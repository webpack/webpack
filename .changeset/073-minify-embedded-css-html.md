Add `renderEmbeddedSource` to transform source one language embeds in another: a compilation hook for CSS and HTML in JavaScript, and a serializer option for an inline `<style>`, `<script>`, every `style=""` (SVG's included), an `<svg>` subtree, an `<iframe srcdoc>` document, and a `url()` `data:` payload.
